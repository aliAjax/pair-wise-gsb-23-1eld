# hxwl-09 半导体洁净室巡检

洁净等级阈值、粒子计数与异常处理看板（离线优先）。

## 技术栈

React + Vite + TypeScript + CSS，本地持久化使用 localStorage（操作日志 + 快照）。

## 本地运行

```bash
npm install
npm run dev
```

开发端口：5109

## 领域逻辑验证

```bash
npm run verify
```

覆盖：冲突合并、校准重算、崩溃恢复、幂等去重、旧记录待核（28 项断言）。

## 离线协作规则（对应夜班无网场景）

- **断网续作**：巡检记录、异常处理单、校准批次全部先落本地操作日志（Op Log），断网时照常工作；恢复连接后点「恢复连接并合并」，先推出待同步记录，再拉取对端记录归并。
- **冲突合并**：同一房间同一时段出现两份记录时，两份原始值都保留并标红差异；复核员按**现场封条时间**选用一份（界面默认建议封条最早的一份），上传/到达时间再晚也不能盖掉现场先后。未选用记录的待审批结论作废，原始值永久保留。
- **校准批次变更**：未审批的异常结论全部失效并按新批次阈值重算（重算报告列出失效/重算/转正常/新检出数量）；已确认的处理单冻结当时的阈值快照与校准编号，不受变更影响。
- **崩溃恢复**：每次变更即时持久化；「封存交接批次」打一个一致性快照。浏览器崩溃后从最近完整交接批次恢复，重放未封存批次中已提交的操作，再只补未完成项（未评估记录、未登记待同步等）。所有操作带幂等键，处理单 id 由记录 + 校准批次确定性生成，重复提交/重放不会多出处理单。
- **旧记录待核**：缺少校准编号的旧记录只挂「待核」单，无阈值快照，不参加新审批，审批按钮对其不可操作。

## 目录结构

- `src/domain/types.ts` — 领域模型（记录 / 处理单 / 校准批次 / 操作日志 / 交接批次）
- `src/domain/core.ts` — 纯逻辑：评估、冲突归组、复核、校准重算、恢复补做、幂等应用
- `src/domain/store.ts` — 持久化、操作日志、崩溃恢复、同步合并（含模拟对端存储）
- `src/App.tsx` — 五个页签：巡检记录 / 冲突复核 / 异常处理单 / 校准批次 / 交接与同步
- `verify-domain.ts` — 领域逻辑验证脚本

## 演示路径

1. 默认断网。在「巡检记录」离线录入一条超限记录 → 本地生成待审批处理单。
2. 「交接与同步」→「模拟对端上传」→ 切为在线 →「恢复连接并合并」→「冲突复核」按封条时间选用。
3. 「校准批次」启用新批次（收紧 20%）→ 查看重算报告与失效/保留的处理单。
4. 「交接与同步」→ 录入若干操作后不封存 →「模拟浏览器崩溃」→ 页面刷新后显示恢复报告。
